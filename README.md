# Krish Patel Personal Website

## Upload correctly to GitHub Pages
Upload BOTH files from this folder:
- `index.html`
- `style.css`

They must be in the repository root (not inside another nested folder).

If the site appears as plain HTML, the stylesheet is missing or its filename/path does not match. Make sure it is exactly `style.css` and that `index.html` contains:
`<link rel="stylesheet" href="style.css">`

## Before publishing
1. Replace `YOUR-USERNAME` in `index.html` with your GitHub username.
2. Check social profile links and update them if needed.
3. GitHub repository Settings → Pages → Deploy from branch → `main` → `/ (root)`.

The website uses Google Fonts; if external fonts are blocked, it falls back to system fonts.
